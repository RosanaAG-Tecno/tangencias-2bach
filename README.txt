TANGENCIAS · DIBUJO TÉCNICO II · VERSIÓN AMPLIADA

Abre index.html para comenzar. Todas las páginas, SVG y scripts pueden ejecutarse localmente sin servidor; las fuentes externas son opcionales.
Para GitHub Pages: sube TODOS los archivos HTML, CSS y JS de esta carpeta a la raíz del repositorio tangencias-2bach. Mantén index.html en la raíz.

La web conserva los módulos originales e incorpora: potencia/eje radical/centro radical, enlaces, tangentes a cónicas, banco de 18 problemas avanzados con pistas y soluciones y diagramas escalonados.
Los problemas PAU orientativos son originales; no se presentan como exámenes oficiales. Las figuras son esquemáticas, no a escala.
Referencia curricular: RD 243/2022 (BOE), criterio 2.2 y criterio 2.3, y programación LOMLOE de Dibujo Técnico II en Asturias.
