TANGENCIAS — DIBUJO TÉCNICO 2.º DE BACHILLERATO

1. Abre index.html en Chrome, Edge o Firefox.
2. Para publicar en GitHub Pages, sube todos los archivos (incluidos styles.css y app.js) a la raíz del repositorio y activa Settings > Pages > Deploy from a branch > main / root.
3. Las páginas funcionan sin conexión, salvo la fuente web opcional: si no hay internet se usa una fuente de sustitución.
4. Los esquemas SVG no están a escala: el alumnado debe respetar las dimensiones del enunciado en papel.
5. Las respuestas del test se procesan localmente y no se almacenan.
